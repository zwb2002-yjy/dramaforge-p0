# ADR-0003：P0 黄金样本 Provider Gate 组合

**状态：ACCEPTED / 已批准**

**提案日期：2026-08-01**

**批准日期：2026-08-05**

**批准人：产品负责人（@zwb2002-yjy）**

**决策范围：P0 主黄金样本的真实 Provider 覆盖、手工媒体角色和验收费用授权**

## 背景

P0 冻结需求要求使用 3-5 场、至少 10 Shot、至少 1 名主角的样本完成从 Project、Brief/Plan、资产、生成、审核到交付的完整闭环。当前合同同时允许 Provider 不可用时显式失败或使用受审计手工媒体，因此“产品可降级完成”和“发布时如何证明真实 Provider 主链”是两个不同问题。

仓库已有以下事实：

- 正式路径在 `APP_ENV != test` 时禁止隐式 Fake Adapter。
- 历史候选曾使用真实文本、真实图像、真实视频和本地 TTS 完成 10 Shot 媒体交付，但人脸 Gate 与 DAG 顺序未通过。
- 本地 eSpeak NG TTS 已作为 `local_tts` Adapter 落地，不需要外部 Key且 Provider 成本为零。
- 受审计手工媒体会形成注册节点的 NodeRun、Artifact、操作者、哈希、媒体元数据、审核与零 Provider 成本，可证明降级能力。
- 真实文本、图像和视频调用会产生外部费用，且受网络、账号、额度和 Provider 状态影响。

若不固定主黄金样本组合，团队可能用全手工媒体证明“交付闭环”，却没有证明真实生成主链；若要求所有节点都使用外部 Provider，又会把没有必要外部化的 TTS、字幕、审核和合成变成额外付费依赖。

## 提案

P0 主黄金样本采用以下组合：

| 节点能力 | 主黄金样本要求 |
|---|---|
| Brief / Plan | 已授权的真实文本 Provider |
| Keyframe | 真实图像 Provider，并实际绑定 Canonical Reference |
| Video | 真实视频 Provider，并回链对应 Keyframe |
| Voice | 私有部署栈内 `local_tts` / eSpeak NG |
| Prompt、Subtitle、Face/Drift/Continuity Review、Composite | 受控本地执行器 |

受审计手工媒体单独验证无 Key、Provider 故障或人工接管时的降级路径，不替代主黄金样本中的真实文本、图像或视频调用。

该要求只定义发布验收证据，不取消产品中的手工创作、手工媒体或 Provider fail-closed 路径，也不批准任何一次实际费用。每次真实验收运行仍须单独取得费用授权并记录 Provider 配置摘要、操作次数、实际成本和失败清单。

## 接受条件

本 ADR 只有在产品负责人明确批准后才转为 `ACCEPTED`。接受时必须同步：

1. 将组合写入 `01_项目总需求.md` §3.1 和产品路线图。 → **已完成（2026-08-05）**
2. 在 `02_全栈技术栈锁定表.md` 固定主黄金样本的 Voice Adapter。 → **已完成（2026-08-05）：`local_tts`（eSpeak NG）**
3. 更新 formal proof、Section 3.1 Gate 和 Playwright 真实 10 Shot 断言。 → **核对确认：现行断言已以真实 Agent 为主证据，手工仅显式 no-key fallback；候选提交 `177d7cb` 上的同源正式运行见 `docs/开发执行检查点.md`**
4. 明确单次验收费用上限、授权人和可使用的 Provider 账号。 → **见下方“费用授权记录”**
5. 保留手工媒体降级用例，不允许其关闭主黄金样本真实 Provider Gate。 → **已保留**

## 未批准期间的口径

- 当前产品标签继续为“P0 功能候选版”。
- `01`-`06` 中现有的 fail-closed、BYOK、预算、ProviderOperation、手工媒体和可追溯交付合同继续有效。
- 工程可以继续修复 GraphEdge、执行顺序、人脸血缘、审核阻断和不产生外部费用的自动化测试。
- 不得以本提案发起付费 Provider 运行，不得声称该组合已成为冻结需求。

## 备选方案

### A. 接受本提案

优点：同时证明真实生成主链和私有部署本地执行；费用与外部依赖范围相对可控。

### B. 允许 Video 使用手工媒体

优点：降低费用与长任务超时风险。缺点：P0 发布证据无法证明真实视频 Adapter、轮询、成本与失败恢复主链。

### C. 主黄金样本全部允许手工媒体

优点：最稳定、成本最低。缺点：只能证明治理和交付链，不能证明 AI 生成产品的关键外部集成，不建议作为 P0 发布 Gate。

### D. Voice 必须使用外部云 TTS

优点：可能获得更好的声音质量。缺点：增加 Key、费用、隐私和 Provider 故障面，而当前 P0 的核心风险不在语音质量，不建议。
