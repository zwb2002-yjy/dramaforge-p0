**状态：ACTIVE / 唯一排期与放行计划**\n**计划区间：2026-08-25 至 2026-09-15**

> 2026-08-25 用户已确认采用《DramaForge 专业版产品与开发最终方案_完整交互版.md》。此前“零基础四阶段向导”降级为兼容模式维护；本路线图优先完成专业工作台、画布事实源、资产版本、正式/实验双线与可追溯生产链。

## 1. 交付目标

发布一个核心体验稳定的自托管开源版本：专业个人创作者围绕场景、镜头和资产完成多镜头作品，能够查看实际请求和 Artifact 血缘、局部修复、比较实验分支并导出。用户确认、Provider 能力证据、质量 Gate、人工审片和安全边界保持硬约束；预算/计费不进入专业版产品体验。

## 4. 不得延期的能力

专业画布事实源、助手确认边界、有效请求、局部修复、Artifact 血缘、质量 Gate、安装/恢复/导出和安全必须保留；预算/计费不作为专业 Gate。可以延期第二模板、趋势 API、非核心 Provider 适配和专业模式便利功能。

## 5. 协作与合并顺序

Schema/迁移 → Domain Command/API → Media/Quality → UI → E2E/真实证据。共享 Schema、迁移序号、路由聚合和锁文件一次只由一个责任线修改；每次合并后先跑受影响测试再继续。
