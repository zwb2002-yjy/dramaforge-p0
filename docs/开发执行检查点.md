## 当前产品与效果缺口

1. 项目级 Canonical 已完成本地实现：试拍为每个角色生成一次，接受后提升为 CharacterReference，正式生产以 cached NodeRun 跨镜头复用；仍需真实 Provider 请求证明同一 Artifact 哈希进入三个镜头；
2. Director 图片和视频已强制走 Unified Provider Path；非 Director 兼容分支仍需等真实 Agnes 验收后清理；
3. Agnes 视频已严格限制为 9:16、24fps、121 帧/约 5 秒和无原生音频；图片 v2 已冻结官方 `1K + 9:16` 合同与 `736x1312` 参考输出，但 v2 Binding 仍需重新做账号 Probe 与质量门禁；
4. `dialogue-post-dub-shot-v1` 没有真正 lip-sync 节点，当前只是视频、TTS、字幕合成后人工验收；
5. 试拍页尚未完整呈现视频、音频、首/中/末帧和质量限制；
6. 新 Director 尚无一部 15–30 秒完整真实作品，也没有三名目标用户无人代操作结果。
