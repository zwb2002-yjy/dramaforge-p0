1. 项目级 Canonical 已完成真实证明：三个 keyframe 请求均引用 Artifact `64ad1657…` 和 SHA-256 `1a4c3233…`，正式生产的 `character_1` NodeRun 为 cached；
2. Director 图片和视频已强制走 Unified Provider Path；非 Director 历史恢复兼容代码按合同保留，不构成 Director 第二路径；
3. Agnes 图片与视频 Binding 已由真实试拍修复验收提升质量门禁；三个成功视频均满足 9:16、24fps、121 帧/约 5 秒和无原生音频请求合同；Provider 成本仍为 `not_reported`；
4. `dialogue-post-dub-shot-v1` 没有真正 lip-sync 节点，当前只是视频、TTS、字幕合成后人工验收；
5. 试拍与修复审阅 UI 已展示真实视频、首/中/末帧、音频、请求和限制，并记录用户接受主观质量限制；这不等同于模型效果已通过独立视听评测；
6. 已有一部 15.17 秒、单主角三镜头真实作品及四项交付；尚无三名目标用户无人代操作结果。
