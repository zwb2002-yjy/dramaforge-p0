## 当前产品与效果缺口

1. Canonical 仍需收敛为项目级资产并跨镜头复用，不能按镜头重复生成；
2. Agnes 媒体主链尚未完全收敛到唯一 Unified Provider Path；
3. Agnes 首版可信能力仍应限制为已验证的 9:16、24fps、121 帧/约 5 秒和无原生音频；
4. `dialogue-post-dub-shot-v1` 没有真正 lip-sync 节点，当前只是视频、TTS、字幕合成后人工验收；
5. 试拍页尚未完整呈现视频、音频、首/中/末帧和质量限制；
6. 新 Director 尚无一部 15–30 秒完整真实作品，也没有三名目标用户无人代操作结果。
