## 不可豁免判定

没有证据=未证明；设计检查不替代unit/PG/E2E；窄测试不支持广泛通过；多个局部结果不拼Full。真实Provider、机构资料外发、正式发布各自授权，测试替身不能假称真实成功。完成Goal前逐主合同条款与交付审核，任何未完成/证据缺失都不标complete。
