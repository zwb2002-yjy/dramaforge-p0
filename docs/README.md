## 3. 状态语义

- `ACTIVE`：当前维护的产品或执行入口。
- `LIVE`：随代码和验收证据持续更新的当前快照。
- `FROZEN / P0`：已冻结的 P0 实施合同；变更必须同步受影响合同和测试。
- `ACCEPTED`：已批准 ADR，可作为实现依据。
- `PROPOSED`：待决策 ADR，不得当成已批准需求。
- `HISTORICAL` / `SUPERSEDED`：只用于追溯，不得覆盖当前入口。

Task 完成、单元测试全绿、历史 Gate 全绿和“代码看起来齐了”都不等于阶段完成。P0 只有在
当前干净候选提交的 formal、Playwright、Section 3.1 Gate、ops 和人工发布批准全部完成后
才可标记完成。

- [`adr/`](adr/)：重要产品、领域和架构决策。ADR 记录理由，不覆盖冻结合同。

- [`runbooks/`](runbooks/)：部署、恢复和发布操作手册。
